# Open Video Saver

Простое расширение для Chrome и Edge. Оно показывает прямые видеофайлы, доступные на текущей вкладке, и передаёт выбранный файл стандартному менеджеру загрузок браузера.

Используйте его только для файлов, которые принадлежат вам или на скачивание которых у вас есть разрешение.

## Что умеет

- ищет открытые прямые ссылки на `MP4`, `WebM`, `MOV`, `M4V`, `OGV` и `OGG`;
- работает по нажатию на значок расширения только на активной вкладке;
- не отправляет URL и данные на внешний сервер;
- сохраняет файл через обычную систему загрузок браузера.

## Ограничения

Расширение намеренно не обходит DRM, платный доступ, авторизацию, CAPTCHA, подписки или другие меры защиты. Оно не поддерживает `blob:`-URL, HLS (`.m3u8`), MPEG-DASH (`.mpd`) и другие защищённые/сегментированные потоки.

## Установка в Chrome / Edge

1. Скачайте или клонируйте этот репозиторий.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** / **Load unpacked**.
5. Выберите папку этого репозитория — ту, где находится `manifest.json`.

## Использование

1. Откройте страницу с вашим открытым видео.
2. Нажмите значок **Open Video Saver** в панели расширений браузера.
3. Выберите найденный файл и нажмите **Скачать**.

Если файл не показан, вероятно, ссылка не является прямым видеофайлом либо видео защищено/транслируется сегментами. В этом случае расширение не пытается обходить ограничение.

## Разработка

Это Manifest V3-расширение без сборки и внешних зависимостей. После изменения файлов нажмите кнопку обновления расширения на странице `chrome://extensions` или `edge://extensions`.
